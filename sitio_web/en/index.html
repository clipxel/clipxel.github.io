Is this for you?

When does CLIPXEL Studio help?

If your situation matches any of these, it was made exactly for this.

Hot sensor pixels

The classic bright dot that always shows up in the same spot, especially in long exposures or night shots.

Dead sensor pixels

A black or signal-less dot that got stuck after a knock, a drop, or simple wear.

Laser-damaged sensor

Stage lights, projectors, or laser pointers that burn an exact spot on the sensor.

Night recordings

The higher the ISO, the more hot pixels stand out — and in video, they show up in every single frame.

Same spot, throughout the video

If the defect always appears in the same position in the frame, a single mask fixes it across every frame.

Footage that can't be reshot

A one-of-a-kind take, an event that already happened — when reshooting isn't an option.

The wizard

Mark it once. It's fixed in every frame.

No touching up frame by frame: the same flow you see when you open the app is four steps — pick the clip, mark the defect once, choose the repair engine, and process the whole batch.

Load your videos

04 · Process

Repair the whole batch

Applies the mask to every frame of the clip, automatically. You can cancel at any time without leaving half-finished files.

So you know what to expect

CLIPXEL Studio doesn't replace a sensor repair.

It's designed to remove permanent, fixed-position defects that appear in the same spot in every frame. It doesn't fix lens dirt, blur, image noise, or moving objects — for that, this tool isn't the right one.

Before installing

Frequently asked questions

Do I need to know how to code or install Python?

No. The Windows installer bundles everything, ffmpeg included. It installs like any other program and opens from the Start menu.

Do my videos get uploaded to a server?

Never. All processing runs on your own computer. CLIPXEL Studio doesn't need an internet connection.

Does it work with cameras other than the Sony A7III?

Yes. It was first tested on the A7III because that's where the original defect appeared, but the mask brush and both repair engines work with any clip where you can photograph the damaged spot, regardless of the pixel's color.

What happens if I cancel mid-batch?

The clip being processed at that moment is discarded along with its partial file; clips already finished stay saved.

Which engine should I use?

Start with Blur to quickly check the mask is well placed across the whole batch, then switch to OpenCV Inpainting for the final export.
